# Feishu A：基础操作录制脚本（LIVE）

**目标：** 只证明导航、搜索、筛选、打开详情、返回。不要写入、发布、交易或发送。

## 启动

在仓库根目录执行：

```bash
bsk browsers
python experiments/browser-use-jev-ultrafast/field-demo/start_recording.py \
  --script basic --mode live --browser <browser-id> --run
```

录制面板出现后点击开始。脚本文件名和 trace purpose 必须保留 `LIVE / FEISHU / BASIC`。

## 逐步动作

1. 打开飞书首页，确认不是登录页、验证码页或风控页。
2. 用页面可见的搜索入口搜索一个你有权访问的文档、会话或应用。
3. 等结果稳定后，观察结果数量、标题和来源；不连续滚动加载大量结果。
4. 使用页面已有的一个筛选条件，例如类型、时间或来源。
5. 打开一个搜索结果详情。
6. 停留 2 秒，让页面状态稳定；记录页面标题和来源，不复制密码、Token 或私密字段。
7. 点击页面返回，确认回到搜索结果页。
8. 点击录制面板 Finish，停止录制。

## 每步观察点

- 首页：页面可达、登录态、无验证码/风控。
- 搜索：搜索词、结果标题、来源区域。
- 筛选：筛选条件是否显示、结果是否变化。
- 详情：标题、来源、时间等当前可见事实。
- 返回：路由或页面标题回到搜索结果。

## 证据

- `recordings/.../trace.json`：连续原始动作证据。
- 若页面变化导致 ref 失效：不要复用旧 ref，重新 observe/snapshot，并把失败保留在 trace。

## 停止条件

完成返回即停止。遇到登录、验证码、风控、页面异常或误点风险，立即停止并人工接管。
