LIVE

录制前置

  1. 确认用户已登录目标站点；遇到登录、验证码或风控立即人工接管。
  2. 使用 record_ready.py preflight --site feishu 检查 bsk 连接。
  3. 使用 bsk trace 的 --redact-values；不得录制密码、验证码、Token 或 Cookie。

最快可录制入口：飞书基线

打开飞书

A 基础操作

导航 → 搜索一个用户有权访问的文档/会话 → 筛选 → 打开详情 → 返回。全程不写入、不发布、不交易。

B 可见数据读取

只读取当前可见且有权访问的标题、时间、来源、状态；在本地记录结构化字段与来源页面，不批量抓取。

C 实时回复

读最新真实消息 → Jev 判断意图/风险/下一动作 → 生成候选回复或模板 → 填入输入框；发送按钮保持人工确认锁定。
